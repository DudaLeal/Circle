# 🔵 Disappearing Circles (Círculos Interativos)

Aplicação web interativa com foco em manipulação da DOM, onde o usuário pode gerar e remover círculos coloridos dinamicamente.

---

## 📌 Sobre o Projeto
Este projeto foi desenvolvido como parte da disciplina de **Desenvolvimento Web** do curso de **Ciência da Computação** na **UFRJ**. 

O objetivo principal foi praticar a lógica de programação no lado do cliente (Client-side) e a manipulação intensiva do *Document Object Model* (DOM) via JavaScript, lidando com criação e destruição de elementos HTML em tempo de execução, gerenciamento de eventos (Event Listeners) e classes de CSS.

## 🛠️ Tecnologias e Ferramentas
* **Linguagem:** JavaScript
* **Estrutura e Estilização:** HTML5 e CSS3

## 🎯 Principais Funcionalidades
* Geração de uma quantidade específica de círculos na tela.
* Geração de uma quantidade aleatória (entre 1 e 10) de círculos com cores sorteadas (vermelho, amarelo ou azul).
* Remoção em massa de círculos baseada no filtro de cor.
* Interatividade por clique: ocultar individualmente cada círculo ao ser clicado (`display: none`).
* Botão para reset (limpar todos os círculos da tela).

## 🚀 Como Executar o Projeto
1. Clone este repositório:
   
```bash
git clone [https://github.com/DudaLeal/Circle.git](https://github.com/DudaLeal/Circle.git)
```
2. Acesse a pasta do projeto.
3. Abra o arquivo `index.html` no seu navegador e interaja com os botões gerados na tela.
